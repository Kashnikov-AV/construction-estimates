# Инструкция по запуску Telegram бота для обработки смет

## Требования

- Python 3.8+
- Установленные зависимости:
  - `aiogram>=3.14.0` (Telegram Bot API)
  - `aiogram-dialog>=2.6.0` (управление диалогами с виджетами)
  - `pandas` (обработка данных)
  - `openpyxl` (чтение .xlsx файлов)
  - `xlrd` (чтение .xls файлов)
  - `aiohttp` (асинхронные HTTP запросы)

## Установка зависимостей

```bash
pip install aiogram aiogram-dialog pandas openpyxl xlrd aiohttp
```

## Запуск бота

1. Перейдите в директорию с ботом:
   ```bash
   cd /workspace/bottapp
   ```

2. Запустите бота:
   ```bash
   python app.py
   ```

## Использование

После запуска бот будет ждать сообщения от пользователей в Telegram.

### Команды:

- `/start` - запуск диалога загрузки сметы
- `/help` - справка о возможностях бота
- `/status` - проверка работоспособности бота

### Обработка файлов через диалог:

1. Отправьте команду `/start` для начала работы
2. Бот откроет диалог загрузки файла
3. Отправьте файл сметы в формате `.xls` или `.xlsx`
4. Бот покажет прогресс обработки с помощью виджета Progress
5. Вы получите обратно CSV файл (или ZIP архив, если в смете несколько листов)

### Альтернативно - прямая отправка файла:

Просто отправьте файл боту без команды - он автоматически запустит процесс обработки.

## Примечания

- Максимальный размер файла: 20 МБ (ограничение Telegram)
- Бот использует прокси-сервер для работы с Telegram API
- Все логи выводятся в консоль
- **Увеличенные таймауты**: 
  - Сессия: 300 секунд (total), 30 (connect), 120 (sock_read), 30 (sock_connect)
  - Polling: 30 секунд между запросами
- **aiogram-dialog**: используется для управления состояниями и отображения прогресса
- **Виджет Progress**: показывает визуальный прогресс-бар при обработке файла
- **Асинхронная загрузка**: файлы загружаются напрямую во временное хранилище без блокировки основного потока
- **Неблокирующая обработка**: парсинг и экспорт выполняются в отдельном потоке через `run_in_executor()`

## Как это работает

### С использованием aiogram-dialog:

1. Пользователь отправляет `/start` или файл
2. Бот запускает диалог `EstimateState.waiting_for_file`
3. При получении файла вызывается `on_file_received`, который сохраняет file_id и переключает на `EstimateState.processing`
4. Окно обработки отображает виджет Progress с текущим статусом
5. Функция `process_estimate` выполняет пошаговую обработку:
   - Загрузка файла (25%)
   - Чтение файла (50%)
   - Парсинг сметы через `core.estimates.parse_estimate()` (75%)
   - Экспорт в CSV через `core.estimates.export_estimates_to_csv()` (100%)
6. Результат отправляется пользователю, диалог завершается

### Увеличенные таймауты
- `total=300` - общее время операции сессии
- `connect=30` - время подключения
- `sock_read=120` - время чтения сокета
- `sock_connect=30` - время установки соединения
- `poll_timeout=30` - таймаут long polling запросов

### Асинхронная загрузка
- Используется `tempfile.NamedTemporaryFile` для временного хранения
- Прямая загрузка в файл через `bot.download_file(destination=...)` с timeout=300
- Чтение файла через `loop.run_in_executor()` для неблокирующего выполнения

### Неблокирующая обработка
- Тяжёлые операции (парсинг, экспорт) выполняются в thread pool executor
- Основной event loop не блокируется во время обработки файлов
- Виджет Progress обновляется на каждом этапе обработки

## Преимущества использования aiogram-dialog

- **Управление состояниями**: FSM состояния организованы в виде диалогов
- **Виджеты**: готовые компоненты для отображения текста, кнопок, прогресса
- **Навигация**: встроенные механизмы переключения между окнами диалога
- **Масштабируемость**: легко добавлять новые шаги обработки
