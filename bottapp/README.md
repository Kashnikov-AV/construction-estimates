# Инструкция по запуску Telegram бота для обработки смет

## Требования

- Python 3.8+
- Установленные зависимости:
  - `aiogram` (Telegram Bot API)
  - `pandas` (обработка данных)
  - `openpyxl` (чтение .xlsx файлов)
  - `xlrd` (чтение .xls файлов)
  - `aiohttp` (асинхронные HTTP запросы)

## Установка зависимостей

```bash
pip install aiogram pandas openpyxl xlrd aiohttp
```

## Запуск бота

1. Перейдите в директорию с ботом:
   ```bash
   cd /workspace/bottapp
   ```

2. Запустите бота:
   ```bash
   python app.py
   ```

## Использование

После запуска бот будет ждать сообщения от пользователей в Telegram.

### Команды:

- `/start` - приветственное сообщение и инструкция
- `/help` - справка о возможностях бота
- `/status` - проверка работоспособности бота

### Обработка файлов:

1. Отправьте боту файл сметы в формате `.xls` или `.xlsx`
2. Бот обработает файл с помощью функций из модуля `core`
3. Вы получите обратно CSV файл (или ZIP архив, если в смете несколько листов)

## Примечания

- Максимальный размер файла: 20 МБ (ограничение Telegram)
- Бот использует прокси-сервер для работы с Telegram API
- Все логи выводятся в консоль
- **Увеличенные таймауты**: 300 секунд на общую операцию, 120 секунд на чтение/запись
- **Асинхронная загрузка**: файлы загружаются напрямую во временное хранилище без блокировки основного потока
- **Неблокирующая обработка**: парсинг и экспорт выполняются в отдельном потоке через `run_in_executor`

## Как это работает

1. Бот получает файл от пользователя
2. Файл асинхронно загружается во временное хранилище с увеличенными таймаутами (300 сек)
3. Содержимое читается в отдельном потоке через `asyncio.run_in_executor()`
4. Вызывается функция `core.estimates.parse_estimate()` для парсинга сметы (в executor)
5. Вызывается функция `core.estimates.export_estimates_to_csv()` для экспорта в CSV (в executor)
6. Результат отправляется пользователю обратно

## Особенности реализации

### Увеличенные таймауты
- `total=300` - общее время операции
- `connect=30` - время подключения
- `sock_read=120` - время чтения сокета
- `sock_connect=30` - время установки соединения

### Асинхронная загрузка
- Используется `tempfile.NamedTemporaryFile` для временного хранения
- Прямая загрузка в файл через `bot.download_file(destination=...)`
- Чтение файла через `loop.run_in_executor()` для неблокирующего выполнения

### Неблокирующая обработка
- Тяжёлые операции (парсинг, экспорт) выполняются в thread pool executor
- Основной event loop не блокируется во время обработки файлов
