# Инструкция по запуску Telegram бота для обработки смет

## Требования

- Python 3.8+
- Установленные зависимости:
  - `aiogram` (Telegram Bot API)
  - `pandas` (обработка данных)
  - `openpyxl` (чтение .xlsx файлов)
  - `xlrd` (чтение .xls файлов)
  - `aiohttp` (асинхронные HTTP запросы)
  - `python-dotenv` (загрузка переменных окружения из .env файла)

## Установка зависимостей

```bash
pip install -r requirements.txt
```

Или вручную:
```bash
pip install aiogram pandas openpyxl xlrd aiohttp python-dotenv
```

## Настройка секретных данных

1. Создайте файл `.env` в директории `/workspace/bottapp/`:
   ```bash
   cd /workspace/bottapp
   cp .env.example .env
   ```

2. Откройте файл `.env` и заполните его своими данными:
   ```
   BOT_TOKEN=ваш_токен_бота_от_BotFather
   PROXY_URL=https://gentle-tree-1a2f.fln5kqj50.workers.dev
   ```

   **Важно:** 
   - `BOT_TOKEN` — обязательный параметр. Получите токен у @BotFather в Telegram
   - `PROXY_URL` — опциональный параметр (используется прокси по умолчанию, если не указан)

3. **Никогда не коммитьте файл `.env` в систему контроля версий!** Он уже добавлен в `.gitignore`.

## Запуск бота

1. Перейдите в директорию с ботом:
   ```bash
   cd /workspace/bottapp
   ```

2. Убедитесь, что файл `.env` создан и содержит корректные данные

3. Запустите бота:
   ```bash
   python app.py
   ```

## Использование

После запуска бот будет ждать сообщения от пользователей в Telegram.

### Команды:

- `/start` - приветственное сообщение и инструкция
- `/help` - справка о возможностях бота
- `/status` - проверка работоспособности бота

### Обработка файлов:

1. Отправьте боту файл сметы в формате `.xls` или `.xlsx`
2. Бот обработает файл с помощью функций из модуля `core`
3. Вы получите обратно CSV файл (или ZIP архив, если в смете несколько листов)

## Примечания

- Максимальный размер файла: 20 МБ (ограничение Telegram)
- Бот использует прокси-сервер для работы с Telegram API
- Все логи выводятся в консоль
- **Увеличенные таймауты**: 300 секунд на общую операцию, 120 секунд на чтение/запись
- **Асинхронная загрузка**: файлы загружаются напрямую во временное хранилище без блокировки основного потока
- **Неблокирующая обработка**: парсинг и экспорт выполняются в отдельном потоке через `run_in_executor`

## Как это работает

### Архитектура бота

BottApp — это асинхронный Telegram-бот, построенный на фреймворке **aiogram 3.x**. Он предназначен для автоматической обработки строительных смет в форматах Excel (.xls и .xlsx).

#### Основные компоненты:

1. **Telegram Bot API (aiogram)** — обрабатывает входящие сообщения и файлы от пользователей
2. **Модуль core** — содержит бизнес-логику парсинга, категоризации и экспорта смет
3. **Pandas + openpyxl/xlrd** — библиотеки для работы с Excel файлами
4. **Aiohttp** — асинхронный HTTP-клиент для работы с прокси

#### Принцип работы:

1. **Получение файла**: Бот принимает файл сметы от пользователя через Telegram
2. **Валидация**: Проверяется расширение файла (.xls/.xlsx) и размер (макс. 20 МБ)
3. **Загрузка**: Файл асинхронно загружается во временное хранилище с увеличенными таймаутами (300 сек)
4. **Чтение**: Содержимое файла читается в отдельном потоке через `asyncio.run_in_executor()`
5. **Парсинг**: Вызывается функция `core.estimates.parse_estimate()` для извлечения данных из всех листов Excel
6. **Категоризация**: Каждая позиция сметы классифицируется на:
   - 🟢 **Материалы** — товары, конструкции, изделия
   - 🔵 **Работы** — услуги, операции, монтажные работы
   - 🟡 **НР/СП** — накладные расходы и сметная прибыль
   - ⚪ **Заголовки/Итоги** — служебные строки
7. **Расчёт сумм**: Подсчитываются_totals по категориям (материалы и работы)
8. **Экспорт**: Создаётся новый Excel файл с двумя листами:
   - **Материалы** — все позиции категории "Материал"
   - **Работы** — все позиции категории "Работа"
9. **Отправка результата**: Пользователь получает сообщение со сводкой и готовый Excel файл

### Технические особенности

#### Увеличенные таймауты
- `total=300` — общее время операции
- `connect=30` — время подключения
- `sock_read=120` — время чтения сокета
- `sock_connect=30` — время установки соединения

#### Асинхронная загрузка
- Используется `tempfile.NamedTemporaryFile` для временного хранения
- Прямая загрузка в файл через `bot.download_file(destination=...)`
- Чтение файла через `loop.run_in_executor()` для неблокирующего выполнения

#### Неблокирующая обработка
- Тяжёлые операции (парсинг, экспорт) выполняются в thread pool executor
- Основной event loop не блокируется во время обработки файлов
- Бот может обрабатывать несколько запросов параллельно

#### Безопасность
- Секретные данные (BOT_TOKEN, PROXY_URL) хранятся в файле `.env`
- Файл `.env` исключён из системы контроля версий через `.gitignore`
- Загрузка переменных окружения через библиотеку `python-dotenv`
